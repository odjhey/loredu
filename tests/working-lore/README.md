# working-lore — M3, the bounded context packet

Catalog rows **T40–T45**: an empty scope returning a definitive empty packet with a
basis and exit 0; `max_items`/`max_chars` respected as the record count grows 10×;
superseded claims omitted from the default packet but still reachable by handle;
conflicts and needs-revalidation surfacing in attention sections; every handle in a
packet resolving through show/history; and a stale basis detected after exactly one
new relevant record.

The property under test is *boundedness with reachability* — a packet that grows
with the store has failed even when every assertion about its content passes.
Row **T75** (a section at its budget stating its full count and carrying a
continuation handle) pairs with the pagination rows in `../cli-conformance/`.
